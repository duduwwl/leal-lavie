# Leal Lavie — loja editorial

Site estático responsivo inspirado no `DESIGN (3).md`, com identidade da Leal Lavie em vermelho profundo, creme, blush e dourado.

## Páginas

- `index.html` — landing page organizada com manifesto, destaques e navegação.
- `perfumes.html` — catálogo exclusivo com 20 perfumes reais, preços fictícios, busca, filtros por perfil, formato e família olfativa, ordenação e favoritos.
- `checkout.html` — checkout demonstrativo com dados pessoais, endereço, entrega para todo o Brasil, retirada em Lavras, Pix e cartão de débito/crédito.

## Observações

- Sacola e favoritos persistem no navegador com `localStorage`.
- A logo foi recriada em SVG a partir da referência visual pública do perfil `@leallavie`.
- As fotos são imagens editoriais públicas usadas como placeholders de produto; substitua pelas fotos oficiais autorizadas da loja quando disponíveis.
- O checkout é visual/demonstrativo: não processa pagamentos reais nem confirma estoque.

Abra `index.html` diretamente ou sirva esta pasta com um servidor HTTP local.
